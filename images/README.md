# Folder Gambar untuk Showroom Garasi Mobil

Silakan letakkan aset gambar Anda di folder ini:

1. `banner-mobil.jpg`
   - Digunakan sebagai gambar banner di bagian Hero section atas.
   - Ukuran ideal: 1200 x 800 piksel (horizontal/lanskap).

2. `fallback-mobil.jpg` (Opsional)
   - Digunakan sebagai gambar cadangan jika foto dari server API gagal dimuat.
   - Ukuran ideal: 800 x 500 piksel.

*Catatan: Foto mobil dalam katalog sudah terhubung dan diambil secara otomatis dari API resmi panitia (`https://api-web.dnccudinus.org/api/mobil`).*
